phishguard

Paste a link to score it for phishing risk. Only the text of the link is read. The page is never opened.

Defanged links are fine: hxxp, [.], (.), and [:] are turned back into a normal URL.

Warning rules

Simple checks on the full URL. They are shown to you but are not inputs to the model.

    Feature contributions

    This model can report how far each feature pushed the score. Positive values push toward phishing.

    What the model saw

    FeatureValue
    A learning project, not a production security control. A lexical model cannot see page content, certificates, or domain reputation.
